
# MVV Provider

Values are obtained from the public widget data API. You can obtain them by inspecting the request in the [MVV developer page](https://www.mvv-muenchen.de/service-hilfe/mvv-content-fuer-entwickler/baukasten-fuer-haltestellen-abfahrtsmonitore/).

To obtain the correct `STATION_ID`, you need to get the query parameter `stop_id` after selecting for the desired stop (It is the request for querying available lines). For example, `München, Marienplatz` is `de:09162:2`

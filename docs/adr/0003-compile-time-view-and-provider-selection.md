# Pick the view and provider at compile time, independently

Each display and each data source is its own folder under `src/view/` or `src/provider/`, which defines `setupBoardView()` or `setupDepartureProvider()` (`include/setup.h`). `scripts/select_modules.py` builds `main.cpp` with exactly one folder of each, taken from the `VIEW` / `PROVIDER` environment variables, falling back to `custom_view` / `custom_provider` in `platformio.ini`; `main.cpp` only sees `BoardView&` and `DepartureProvider&`. This lets someone with a different panel size or data source add a folder without editing the view or provider that already works, or `main.cpp`, and combine any view with any provider without an env per combination. We rejected runtime selection (a factory switching on a config value), because it would link every display driver and TLS stack into a 1.3 MB app partition (the `pio run` size report) that uses only one of each. We also rejected `#if` macros in `main.cpp`, because every new view would then edit shared code. We used a script rather than `${sysenv.VIEW}` in `build_src_filter`, because PlatformIO has no default for an unset variable, and `view//` would silently match every view. The cost is that all combinations share one build directory and one `lib_deps` list.

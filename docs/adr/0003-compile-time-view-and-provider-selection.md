# Pick the view and provider per PlatformIO env at compile time

Each display and each data source is its own folder under `src/view/` or `src/provider/`, which defines `setupBoardView()` or `setupDepartureProvider()` (`include/setup.h`). A PlatformIO env picks one of each with `build_src_filter`, and `main.cpp` only sees `BoardView&` and `DepartureProvider&`. This lets someone with a different panel size or data source add a new folder and env, without editing the view or provider that already works, or `main.cpp`. We rejected runtime selection (a factory switching on a config value), because it would link every display driver and TLS stack into a 1.3 MB app partition (the `pio run` size report) that uses only one of each. We also rejected `#if` macros in `main.cpp`, because every new view would then edit shared code. The cost is one env per device/provider combination, and the linker, not the compiler, reports a missing or duplicate choice.
